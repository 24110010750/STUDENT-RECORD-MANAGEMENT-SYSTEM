Today, I am uploading my mini project to GitHub titled
“Student Record Management System (SRMS)”.

This project is developed using C programming and is designed to manage student data in a digital way instead of paper-based records.

In this project, I have implemented the following main features:
	•	Login system using username and password stored in a file
	•	Role-based access for Admin, Staff, and Guest
	•	Adding new student records
	•	Displaying all student records
	•	Searching students by roll number
	•	Updating student details
	•	Deleting student records

The project uses file handling with two main files:
	•	credentials.txt for login details
	•	students.txt for student data

I have used modular programming concepts by separating code into functions like:
loginSystem(), addStudent(), searchStudent(), etc.

This project helped me understand:
	•	File handling
	•	Structures in C
	•	Role-based access
	•	Real-time data management
